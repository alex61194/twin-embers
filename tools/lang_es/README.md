# Spanish FireRed tools (work in progress)

Scripts that run **on the owner's PC** next to both ROMs (USA 1.0 and Spain BPRS rev 0).
They only print or write offsets and sizes, never ROM bytes. Their outputs stay on the PC.

- `align.py`, `align2.py`, `align3.py`: how much of the recipe matches between the two ROMs.
- `es_sizes.py`, `es_sizes2.py`: the Spanish length of each text symbol of the recipe (via pointers, then contiguous runs). They need the recipe's `entries-*.json`/`units-*.json` in `recipe/`.
- `es_events2.py` + `scrdis.py` + `script_ops.json`: Spanish layout of `event_scripts` (labels, pointer sites).
  `event_scripts_layout_us.json` is the label/reloc list of pret's `data/event_scripts.o` (USA build).
  `script_ops.json` is generated by assembling each macro of pret's `asm/macros/event.inc`.

Usage: `python3 -I es_events2.py "<USA rom>" "<Spain rom>"`. See STATUS.md and DISENO-event-scripts.md.

`event_scripts_layout_us.json` is not committed (too big for the audit limit). Regenerate it in the cloud or on Linux:
`apt install binutils-arm-none-eabi`, `python3 tools/bootstrap.py`, then in `build/upstream`:
`make tools && make build/firered/data/event_scripts.o`, and dump `arm-none-eabi-nm -n --defined-only`
(symbols t/d) and `arm-none-eabi-readelf -rW` (R_ARM_ABS32 offsets) into
`{"size": 421686, "us_start": 1440180, "syms": [[off, name]...], "relocs": [[off, type, sym]...]}`.

## Event scripts, Spanish object
1. `python3 -I es_events2.py "<USA rom>" "<Spain rom>"` writes `event_scripts_layout_es.json`
   (Spanish offset of every label, and every pointer site paired with its USA relocation).
2. `python3 gen_event_scripts_es.py event_scripts_layout_us.json event_scripts_layout_es.json event_scripts_es.s`
   writes the Spanish `data/event_scripts.s`: labels, `.space` and `.4byte` targets only, no ROM bytes.
   Fed the USA layout as both inputs it reproduces pret's object exactly (same 9,832 symbols, 9,954 relocations,
   421,686 bytes). With the Spanish layout: 420,310 bytes, 9,954 pointer sites (2 Nov 2026).
