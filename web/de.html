Auf deinem 3DS installieren

Drei Wege dorthin. Alle geben dir immer die neueste Version. Du brauchst außerdem dein Paket, twinembers.pak, in SD:/3ds/twinembers/ (oben erstellen).

Am einfachsten auf dem 3DS

Universal-Updater

  1. Öffne Universal-Updater.
  2. Tippe auf Einstellungen (das Zahnrad) → UniStore auswählen.
  3. Tippe auf + und scanne diesen Code.
  4. Der Store wird der Liste hinzugefügt, ohne sich zu öffnen: tippe in der Liste auf Twin Embers.
  5. Installiere twinembers.3dsx (German) (es installiert twinembers-de.3dsx), wenn dein Paket aus dem deutschen ROM stammt. Installiere auch den HOME Menu forwarder, wenn du ein Symbol im HOME-Menü möchtest.
Mit Handy oder PC

Das Spiel herunterladen

  1. Scanne diesen Code mit deinem Handy oder drücke den Knopf.
  2. Er lädt twinembers-de.3dsx herunter, das Spiel für das oben gewählte ROM (twinembers-de.3dsx für das deutsche ROM).
  3. Kopiere es auf die SD-Karte, nach SD:/3ds/twinembers/.
  4. Starte es aus dem Homebrew Launcher.
twinembers-de.3dsx herunterladen
Symbol im HOME-Menü

FBI

  1. Öffne FBI.
  2. Wähle Remote Install → Scan QR Code und scanne diesen Code.
  3. Es installiert das Symbol Twin Embers im HOME-Menü.
  4. Das Symbol startet SD:/3ds/twinembers/twinembers.3dsx, twinembers-es.3dsx oder twinembers-de.3dsx (das neueste, wenn mehrere da sind): hole dir das Spiel zuerst mit einem der anderen zwei Codes.
