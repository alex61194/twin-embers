Install on your 3DS

Three ways to get it. All of them always give you the latest release. You also need your pack, twinembers.pak, in SD:/3ds/twinembers/ (make it above).

Easiest on the 3DS

Universal-Updater

  1. Open Universal-Updater.
  2. Tap Settings (the gear) → Select UniStore.
  3. Tap + and scan this code.
  4. The store is added to the list without opening: tap Twin Embers in the list.
  5. Install twinembers.3dsx, or twinembers.3dsx (Spanish) (it installs twinembers-es.3dsx) if your pack is from the Spanish ROM. Install the HOME Menu forwarder too if you want an icon on the HOME Menu.
With a phone or PC

Download the game

  1. Scan this code with your phone, or press the button.
  2. It downloads twinembers.3dsx, the game for the ROM you chose above (twinembers-es.3dsx for the Spanish ROM).
  3. Copy it to the SD card, in SD:/3ds/twinembers/.
  4. Start it from the Homebrew Launcher.

HOME Menu icon

FBI

  1. Open FBI.
  2. Choose Remote Install → Scan QR Code and scan this code.
  3. It installs the Twin Embers icon on the HOME Menu.
  4. The icon starts SD:/3ds/twinembers/twinembers.3dsx, or twinembers-es.3dsx (the newer when both are there): get the game with one of the other two codes first.
