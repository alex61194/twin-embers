Install on your 3DS, no PC needed

Both codes always point at the latest release on GitHub. You still need the pack above in SD:/3ds/twinembers/.

Universal-Updater

  1. Open Universal-Updater, go to Settings → Select UniStore, add a UniStore (+) and choose the QR code option.
  2. Pick Twin Embers; install twinembers.3dsx and, if you like, the HOME Menu forwarder.

FBI (forwarder CIA)

  1. Open FBI, then Remote Install → Scan QR Code.
  2. Installs TwinEmbers-Forwarder.cia, the HOME Menu icon. The game itself, twinembers.3dsx, still goes in SD:/3ds/twinembers/.
